# 剧情系统

> 用途：新手引导 + 世界观/角色表达。  
> **只写新文案**；立绘用各角色**默认装甲动态**（`portraitLive`），老板娘/指挥官用现有静图。  
> 营地 **不做** 这条剧情线。老板娘第三关后退回营地柜台。  
> 文风参考 Galgame / JRPG：多句推进、声线鲜明、穿插玩家选择；**玩家必须一眼听懂在说什么**。
> 2026-09-15：§八～§九全文按「可读优先」重写（反「句号写在敌上」类黑话）。
> 2026-09-15：§〇.5 对齐 Gal/RPG；代码落地 `storyBeats` + 引导锁营地（`npm run verify-story-guide`）。

## 〇、文案红线（必读）

**反面教材（禁止再写这种）：**

> 「灯不关。活人先走。」／「句号写在敌上。」／「空白权限临时开放。」／「射界终审区交你们。」

玩家会觉得像乱码，不知道自己选了什么、角色答应了什么。

| 要 | 不要 |
|---|---|
| 口语、画面感：「站我后面」「别冲出去」「我们一起回去」 | 协议腔堆砌：「编队写入」「威胁链延长」「括号未闭合」 |
| 选项 = 清楚意图（保护 / 进攻 / 关心） | 选项像黑话口令，选完还要猜含义 |
| 角色术语最多点缀一句，**下一句立刻用白话解释** | 整场只用术语互相打哑谜 |
| 先让人懂剧情，再让人听出性格 | 为了「像 AI」牺牲可读性 |

**角色仍要有声线，但声线 ≠ 难懂：**

- 澪：话短，但说的是路、风、跟上——不是「协议有回声」。
- 芹奈：护人、热的、回来——可以直接说关心。
- 玲：可以说概率，但必须跟一句「别走那条大路」。
- 天音：可以怪，但澪/芹奈/美羽要立刻翻译成「她让我们先打敌人 / 她先退开」。
- 老板娘：机器口吻可以留，但步骤要用「点这里、做这件事」说清。

## 〇.5、对齐市场 Gal / RPG 的对话与引导逻辑

对照常见 Gal（点击续页 + 选项汇合）与手游 RPG 新手引导（高亮 → 操作门闩 → 不可软锁），本系统必须满足：

| 市场惯例 | 本项目对齐 |
|---|---|
| 点击续页 / 打字机 / ▼ | Gal 层：点对话框续句；引导场不可整场跳过 |
| 选项不锁死结局 | 分支只改台词，胜负/掉落不变；汇合后继续 |
| 用做来学，少墙文 | 老板娘每步对应真实 UI 操作（编队/开战/领任务/开箱/装备） |
| 条件幂等，防卡死 | 步骤完成条件可重入；已满足则自动跳过，失败从当前步续 |
| 老玩家不重播 | 已有通关记录的旧档 → 直接 `storyGuideDone` |
| 教学保底 | 引导期内首次开箱**必出可装备的新枪**（防重复碎片软锁） |
| 内容与表现分离 | 文案在 `storyBeats.ts`；播控/门闩在 `StoryGuideSystem`；UI 只消费数据 |
| 可继续加章 | 新关只需加 beat id + 挂 `chapterIndex∈{1,7,12}` 或显式 stage 映射 |

**已排除的矛盾：**

1. ~~芹奈空枪 + 开箱重复变碎片 → 装备步永远完不成~~ → 引导首开保底新枪。  
2. ~~锈币不够开箱~~ → Lv.1 开箱 80，通关+领任务后充足；仍不足时引导提示先领任务。  
3. ~~玩家乱序通关~~ → 步骤看条件不看死顺序（已通关 2 则 `g_stage1` 亦可视为满足若已清 1）。  
4. ~~空编队看板空白~~ → 显示指挥官 `zhujue.png`。  
5. ~~营地随时进打断教学~~ → `!storyGuideDone` 锁底栏营地。

## 一、设计目标

1. 玩家第一次进游戏就明白：**自己是被拆掉战斗模块的矮小指挥官机器人**（`tex/zhujue.png`）。
2. 两个初始 SR（苍羽·澪、白楯·芹奈）**已经跟随**，看板用一段可互动的对话说清「为什么」。
3. 商店老板娘弹出固定话术，带完：**编队 → 战斗 → 领任务 → 买武器 → 装备 → 打到第 3 关**。
4. 第 3 关后引导结束，老板娘回营地；**营地底栏解锁**。
5. 关卡剧情 = 角色声线 + 地域母题 + **玩家可点的指挥官应答**；不写成营地日常。

## 四、玩家身份

玩家 = **指挥官**：灰白圆顶、双红圆眼、锈红胸板、三指爪；身量只到队员腰腹；无战斗模块。

立住方式：

1. 序章 PV/文字（已有）。
2. 空编队看板主位 = 指挥官。
3. 对话里反复确认「小灯 / 锈壳 / 出战名单 / 不能自己开枪」——用玩家听得懂的词。

指挥官话仍短，但**玩家通过选项替他说出来**（见 §六.4），而不是系统自动旁白完事。选项必须一眼能懂（保护 / 进攻 / 关心），禁止黑话口令。

## 五、为何两个 SR 已跟随（设定锚）

- **澪**：检修棚外看见臂壳上同样的「把路打开」，扣上半块能量芯——「行，跟我走。」她认定你会把散落的路线接起来。
- **芹奈**：熔炉城废墟用盾沿撬开塌管，把你背回月台。后来对着「欢迎回来」的空盾钉盒，回了一句「欢迎回来」。她跟着，是为了身后还有人能回家。

叙事状态：**已经跟你，还没被点名出征**（拥有 ≠ 编队）。

## 六、表现规格（Galgame 向）

### 6.1 剧情立绘：默认动态 + 上半身放大（不裁源）

说话人主画面：

1. **只用默认装甲动态** `portraitLive`（与看板/出征原皮一致）。禁止泳装/睡衣/特殊皮，禁止用 emotion-pose PNG 当主立绘。
2. **上半身构图**：对**完整** webm/png 做 `transform: scale(1.4~1.6) translateY(+8%~+14%)`（数值按角色站姿微调），使视口自然落在头～胸～肩（及枪/盾上缘）。
3. **禁止裁切源素材**：
   - 禁止导出半身切图；
   - 禁止 `object-fit: cover` 把头顶/下巴/武器中段切掉；
   - 视口可用 `overflow: hidden` 做取景框，但框内必须**完整包含**头、双肩、胸部以上；若放大后缺头/切手，改 `scale`/`translate`，不要硬裁。
4. 推荐：`object-fit: contain` + 放大平移；背景可用现有战斗/看板底，立绘底层透明 webm。
5. 双人对话：左/右各一上半身动态，当前说话人略亮、略大（scale +0.05），另一方降透明度。
6. 老板娘：静图正面/背面，同样上半身放大规则，不切头。
7. 指挥官：`zhujue.png` 可略小置于对话框旁或选项上方，强调体型差。

### 6.2 对话框与节奏

- 底部对话框（Gal 常见）：姓名条 + 打字机正文 + 「▼」续页。
- 每句可点；**不可一键跳过整场**（引导场）；关卡剧情允许「跳过本场」（首次仍建议看完）。
- 一句可 1～3 行，约 40～90 字；澪/凛仍偏短，但一场要有 **6～14 句** 的起承转合，不是三句收工。
- 气泡类型可作姓名条色/框边区分：对话 / 耳语 / 喊 / 旁白。

### 6.3 战斗中

- **教学关 1-1～1-3**：开战前 **全屏剧情层**（暂停刷怪），播完再开战。
- **之后关键关（章首/小 BOSS/大 BOSS）**：开战前短剧情层（可暂停 8～20 秒），或半透明对话框 + 短暂敌生成延迟。
- 仅普通模式首次；地狱/扫荡不播。

### 6.4 玩家交互（必须有）

每场剧情至少含 **1 次**下列交互（引导场 ≥2 次）：

| 类型 | 说明 | 好例子 | 坏例子 |
|---|---|---|---|
| **意图选项** | 2～3 个指挥官短句，选完角色接话 | 「我躲你后面。」「路交给你。」「小心。」 | 「编队确认。」「句号写在敌上。」 |
| **确认按钮** | 点一下才开战/进下一步 | 【下令开火】【我知道了】 | 【开火窗口·权限校验】 |
| **轻触反馈** | 点立绘有一句反应 | 「别拽枪带啦。」 | 「枪带误差超限。」 |
| **操作门闩** | 编队/领奖/开箱等 | 老板娘说「点开编队，把澪放上去」 | 「编队协议空，请点名」 |

选项 **不改变** 通关与掉落；只改下一句台词。

文案标记约定：

```
【立绘】ashcrow | live-default | bust-zoom
澪「……」
【选项】（括号里可写给策划看的意图，游戏内可不显示）
  A. 「……」　← 保护/跟随
  B. 「……」　← 信任队员
【若 A】澪「……」
【汇合】芹奈「……」
```

## 八、新手引导

```
标题 → 序章 → 看板（指挥官）→ 跟随对话（互动）→ 老板娘引导
→ 编队上澪 → 1-1 剧情+战 → 领任务 → 开箱 → 装备芹奈
```

### 8.1 看板跟随 `hub_follow`

【场景】主城看板。主位指挥官。澪、芹奈以默认装甲动态·上半身放大入画。  
【交互】至少 2 次选项；可点立绘彩蛋。

---

澪（望着你胸口的小灯，语气很稳）  
……还亮着。沙停了。  
指挥官，你现在站的地方，叫零号月台。风从铁轨那边吹过来——我量过，这条路能走。

澪（走近一点）  
检修棚外面那次，我差点把你当成一堆废铁。  
可你臂壳上刻着一句话，跟我脑子里剩下的指令一模一样：「把路打开。」  
我没多问。把半块能量芯扣进你断线的地方，然后说——行，跟我走。

【选项】  
A. 「跟我走。」　← 回应她那句话  
B. 「灯还亮着就好。」　← 她在意的那盏灯  
C. （只亮一下待机灯）「……哔。」　← 小机器人式应答

【若 A】澪（轻轻点头）  
嗯。听到了。  
【若 B】澪（看着小灯）  
那就别灭。灭了，我就得回头找你。  
【若 C】澪（停半秒，像在翻译）  
……也行。有时候一声哔，比说一大堆更让人安心。

【汇合】澪  
后来我是第二个站到你身边的。不是被谁说服，是认定——你会把断掉的路重新接上。  
不过现在还没点我的名字。点了，我才走最前面。没点之前，我就守在你三步外。

---

芹奈（盾轻轻落地，声音柔）  
小个子……别往后缩。  
塌管把你压住那次，你身上的警报叫得好大声。我用盾撬开钢架，一路跟你说「别动，我来」。  
背你回营地的时候，你外壳烫得像刚从炉边爬出来。

芹奈  
后来你在棚外摆了一排空盒子，上面写着「欢迎回来」。  
我站了很久，只拿了一枚钉子，回你一句——欢迎回来。  
不是客套。是我觉得……这里又能被人叫作家了。

【选项】  
A. 「谢谢你。」　← 道谢  
B. 「那你站我后面。」　← 信任她护卫  
C. 「……欢迎回来。」　← 学她那句

【若 A】芹奈（笑意很浅）  
谢什么。能回来的人，才配喝一口热的。  
【若 B】芹奈  
嗯。你要出征，我就站你身后。我不怕挡子弹，怕的是回头一看，后面没人了。  
【若 C】芹奈（眼睛微微发热，仍压着）  
……嗯。这句话，只说给还活着的人听。

【汇合】芹奈  
盾还在，枪也在。你点我的名，这一趟我就负责把大家带回家。  
还没点名之前——我也在。只是在你灯照得到的地方，扫扫沙，留一壶热的。

---

澪（对芹奈极短地点一下头，再看你）  
等会儿柜台后面那个旧机体商店老板娘会来找你。她说话有点怪，但步骤是对的。  
听她的：先把编队点上，我们才能出征。

【轻触彩蛋】  
- 点澪 → 「别拽枪带。差一厘米出门会卡住。」  
- 点芹奈 → 「盾边上有点沙……等会儿我擦。」  
- 点指挥官 → 澪「别自己往铁轨上撞。」／芹奈「小灯，我在这儿。」

播完 → `storyHubFollowSeen`。
