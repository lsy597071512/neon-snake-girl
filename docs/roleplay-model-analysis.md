### 1.4 实际能力优缺点

#### ✅ 强项

```
1. 中文原生支持
   - 阿里海量中文语料训练
   - 中文角色扮演质量天花板（国内云端）
   - 简体/繁体/粤语均可

2. 话题推进（Topic Progression）
   - 能主动引导对话走向
   - 减少"你问一句我答一句"的死板感
   - 适合 NPC 主动发消息场景

3. 倾听共情（Empathetic Listening）
   - 能识别用户情绪并给予回应
   - 适合情感陪伴场景

4. 长上下文
   - 百炼版本：131,072 tokens
   - QwenCloud 版本：32,768 tokens
   - 支持超长剧情/多角色对话

5. Session 缓存
   - 命中缓存的 Token 按隐式缓存计费
   - 对话速度快 30-50%
```

#### ❌ 弱项

```
1. 严格指令遵循差 ⚠️
   - RP-Bench F12：3.17（最低之一）
   - System Prompt 中的复杂规则容易漂移
   - 对于"废土少女倔强但内心柔软"这种复合人设，
     可能无法同时保持多个维度

2. NSFW 内容受限 ⚠️
   - 阿里云强制内容过滤
   - 调教/小黑屋场景会被过滤
   - 不适合成人向内容

3. 类人性（Human-likeness）最低
   - DynSess：2.86（所有模型中最低）
   - 角色"像真人"的感觉弱
   - 容易产生"AI 味"

4. 色情/成人场景弱
   - RP-Bench NSFW 胜率：低
   - 不适合深度调教场景

5. 成本持续累积
   - ¥0.115/1M 输入 + ¥0.287/1M 输出
   - 高频对话场景成本显著
```

## 5. 核心发现 & 项目建议

### 5.1 Qwen Plus Character 真实能力总结

```
优势：                    劣势：
✅ 中文天花板            ❌ 指令遵循差（RP-Bench F12：3.17）
✅ 话题推进好           ❌ NSFW 内容受限（阿里云过滤）
✅ 长上下文（131K）     ❌ 类人性最低（DynSess：2.86）
✅ Session 缓存         ❌ 成本持续累积
✅ 速度稳定             ❌ 非专用 RP 微调
```

**关键弱点**：RP-Bench F12（严格系统提示词遵循）得分 **3.17**，是所有测试模型中**最低之一**。
- 这意味着：当你在 System Prompt 中定义"废土少女 + 倔强 + 内心柔软 + 危机感知 + 社交模式"等多重规则时
- Qwen Plus Character **容易漂移**，无法同时保持所有维度
