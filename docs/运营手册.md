# 锈带纪元 · 运营手册（写给美术背景的开发者）

> 📐 想了解背后的技术原理/架构？见 [激活与账号系统.md](./激活与账号系统.md)。本手册只讲怎么操作。

> 你的工具箱里只有 3 个需要认识的东西，全部双击就能用：
>
> | 文件 | 干什么 |
> |---|---|
> | **码池管理.bat** | 双击 → 浏览器打开管理面板（生成码/看玩家/停用/解绑） |
> | **部署网关.bat** | 只在第一次部署时用过，以后不用碰 |
> | **登录Cloudflare.bat** | 很少用：Cloudflare 登录过期时重新授权 |

## 一、日常卖游戏流程（最短路径）

### 方式 A：爱发电订单号（推荐，零人工发货）

玩家付款后**自动**拿到一个订单号，自己在游戏里输入就能玩。你全程不用发任何东西。

**一次性设置（10 分钟）：**
1. 注册/登录 [爱发电](https://afdian.com) → 右上角头像 → **开发者设置**（或「开放平台」）
2. 记下两个东西：**user_id**（个人主页网址里那串）和 **API Token**（开发者设置里生成）
3. 把这两个值发给我，我配置到网关上（一条命令的事）

**之后卖游戏：**
1. 爱发电 → 创建商品「锈带纪元 测试资格 ¥XX」→ 商品介绍写清楚"付款后用订单号登录"
2. 玩家付款 → 爱发电给他订单号（在「我的订单」里能看到一串数字）
3. 玩家游戏首屏输入：**订单号 + 自己的千问 Key** → 系统自动验证订单真实 → 自动开通
4. 完成。你睡觉的时候也在卖。

### 方式 B：兑换码（手动，适合熟人小圈子）

1. 双击 **码池管理.bat** → 浏览器打开管理面板
2. 「生成新兑换码」：填数量（如 5）→ 点「生 成」→ 点「下载 txt」
3. 把 txt 里的码发给付款的玩家（微信发就行）
4. 玩家游戏首屏输入：**兑换码 + 自己的千问 Key**

### 方式 C：爱发电卡密自动发货（如果后台有此功能）

爱发电创建商品时如果能看到「卡密」类型：把 codes.txt 里的码批量粘贴上传 → 买家付款自动发一个码。效果和方式 A 一样，只是门票从订单号变成了兑换码。

## 二、码池管理面板使用

双击 **码池管理.bat** 后的界面：

| 区域 | 功能 |
|---|---|
| 顶部四个数字 | 总码数 / 有效 / 已停用 / 绑定设备总数 |
| 生成区 | 填数量 → 生成 → 「下载 txt」得到可上传的码文件 |
| 列表 | 每个码的绑定设备数、状态、备注、时间 |
| 每行按钮 | **停用**（退款/滥用时用，玩家立即无法登录）· **解绑设备**（玩家换手机时用） |

数据实时存在 Cloudflare，关掉面板不会丢。

## 三、玩家问题处理速查

| 玩家说… | 你做… |
|---|---|
| "换手机了登不上" | 面板里找到他的码 → 点「解绑设备」→ 让他重新登录 |
| "退款！" | 点「停用」他的码 |
| "码输了显示不存在" | 核对他发的码和你面板里的是否一致（注意没有数字 0 和字母 O） |
| "显示 Key 无效" | 让他回阿里云百炼重新生成 Key，注意 sk- 开头别复制空格 |
| "显示账户额度不足" | 他的千问账户欠费了，让他去百炼充值/领免费额度 |
| "设备数已达上限" | 见换手机；或他真的把码分享给别人了——你可以先问一句 |

## 四、更新迭代流程（改了游戏内容后）

1. 改代码/美术（照常开发）
2. 告诉我"重新打包"，或自己跑之前的打包流程
3. 把新 APK 发给玩家（微信群文件即可），玩家覆盖安装
4. **兑换码、玩家进度（存档）都不受影响**——更新只换游戏本体

> 以后玩家多了（>100），可以加「应用内自动更新提示」：启动时问网关"最新版本号"，低了就弹下载链接。需要时告诉我加。

## 五、钱和账

| 项 | 谁出 | 说明 |
|---|---|---|
| 游戏服务器（Cloudflare） | 你 | 免费额度内（10 万请求/天），私测阶段 = 0 元 |
| AI 对话费用 | **玩家自己** | 玩家自己的千问 Key，用多少付多少给阿里云 |
| 收款 | 玩家付你 | 爱发电会抽成（以平台页面为准），或微信直接收 |

## 六、故障排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 面板打开一直转圈 | 你的代理没开或断了 | 开代理软件后刷新页面 |
| 玩家登录转圈很久 | 玩家网络连不上 youziligames.com | 让玩家开关一下飞行模式重试；多人反馈则告诉我（可能需要优化线路） |
| 部署网关.bat 报登录过期 | Cloudflare 登录态失效 | 双击 登录Cloudflare.bat 重新授权 |
| 打包后 APK 很大 | 正常（高清资产+立绘） | 私测阶段不用管 |
