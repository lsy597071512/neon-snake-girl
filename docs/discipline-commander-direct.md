## 1. 设计意图（Player Promise）

### 1.1 与触手调教的关系

| | **触手调教（现行）** | **指挥官亲自调教（本文）** |
|--|--|--|
| 执行者 | 指挥官侧 **机械触手臂**（`tex/zhujue.png` 爪臂） | **指挥官本体**（矮小废弃机器人）亲自贴身操作 |
| 玩家操作感 | 切姿势 1..N；触手加压 | 切 **阶段 1..5**；每阶段指挥官动作升级 |
| 叙事重心 | 被器械固定、被动承受、复杂矛盾情绪 | **双向生理**：指挥官也会漏油；角色被「人」而非「工具」压制 |
| 成人层级 | 擦边束缚 + 成人 Prompt 字段 | **明确成人事件**；插入 / 多点刺激 / 高潮机油 |
| 资产 | `{Stem}_tiaojiao.webm` + `_1..N` | **新管线** `{Stem}_tiaojiao_cmd_p{1..5}.webm`（命名见 §9） |
| 场景 | 同为负一楼小黑屋、调教皮、同一开关体系 | 同上 |

两套模式 **禁止混用单条 WebM**；进房后由玩家或事件选择「触手 / 亲自」，Prompt 与姿势文案表分开维护。

### 1.2 一句话重心

**指挥官不再只站在场外下指令，而是以小机器人的身躯贴上来，用手、用管道、用全身缠绕，把调教从「被机器玩弄」推进到「被指挥官本人占有」。**

仍属惩罚/威慑工具链（见 [discipline-event.md §1](./discipline-event.md)），不是 pifu05 情趣调情。

### 1.3 指挥官本体规格（全阶段硬锁）

| 项 | 规格 |
|----|------|
| 形象 | 矮小废弃机器人；参考营地指挥官立绘比例（明显小于美少女干员） |
| 核心道具 | 双腿之间的 **主管道**（类阴茎义体出口）+ 可拆卸 **细管道**（乳首 / 会阴 / 后穴） |

| 互动 | 可主动刺激角色，也可被角色乳交 / 夹腿 / 骑压反向刺激而漏油 |

## 2. 强度梯理论（参考网络常见「场景架构」）

本文五阶段对齐业界常用的 **预热 → 递进 → 峰值 → 缓降** 结构，并映射到本游戏的机油 / 敏感点字段：

| 外部分类（参考） | 本玩法阶段 | 强度 1–10 | `stim_intensity` |
|------------------|------------|-----------|------------------|
| 建立场域 / anticipation | 阶段 0（进房 idle，沿用现有） | 1–2 | — |
| 初次接触 / intentional touch | **阶段 1** 掌握 | 3–4 | `1` |
| 持续亲密 / sustained intimacy | **阶段 2** 贴身 | 5–6 | `2` |
| 主动欲望 / penetration entry | **阶段 3** 主管道 | 7 | `3` brief→sustained |
| 多点加压 / peak build | **阶段 4** 双孔+乳首 | 8–9 | `3` sustained |
| 高潮 / catharsis | **阶段 5** 过载 | 10 | `climax` |
| 余韵 / aftercare（可选 UI） | 阶段 5 末 2s 或离房结算 | 回落至 4–5 | `sustained`→`""` |

参考要点（不写进 Prompt 原文，仅供策划/美术理解节奏）：

- **不要跳阶**：每阶段至少 5s 可循环，让玩家感到「多了一层」而非瞬间满级。  
- **双向信号**：指挥官漏油 = 角色身体「赢了一寸」的反馈，利于写矛盾情绪。  
- **峰值后要有落点**：阶段 5 后半拍建议留「颤抖 / 喘息 / 机油滴落」便于 loop 回卷，而不是硬切黑屏。

## 4. 阶段 1 · 掌握·胸域（Grasp）

**目的**：从「被盯着」进入「被触碰」；建立指挥官 **实体在场** 的恐惧/兴奋。  
**敏感区**：`breast` · `nipple`（隔皮衣压迫，无必要露点）  
**建议循环**：5s · 抓握收紧 1 拍 → 拇指碾过乳首 1 拍 → 松半拍 → 再收紧

### 4.1 表现变体（美术可任选 2–3 款 / 角色）

| ID | 构图关键词 | 指挥官动作 | 角色反应锚点 |

## 5. 阶段 2 · 贴身·互磨（Press）

**目的**：从「手」升级到 **全身重量与管道外摩擦**；引入 **双向刺激**（角色也能让指挥官漏油）。  
**敏感区**：`waist` · `crotch_outer` · `butt` · `perineum`（外）· `commander_pipe`  
**机油**：允许 `oil_discharge: both`（brief）；管道口湿润高光、角色腿根反光

### 5.1 表现变体

| ID | 构图关键词 | 指挥官动作 | 角色动作 | 双向要点 |
|----|------------|------------|----------|----------|
| P2-A | 正面贴身站立 | 指挥官贴腹，主管道抵会阴外碾 | 髋前后微磨 | 互磨 |
| P2-B | 腿间夹击 | 指挥官坐地，管道被大腿根夹住 | 腿根收紧 | 指挥官先漏油 |
| P2-C | 乳交位 | 指挥官跪于胸下，管道抵胸沟 | 双乳挤管道 | 指挥官 brief 高潮 |
| P2-D | 背后环腰 | 从后环抱，管道顶臀缝上沿 | 臀后顶 | 角色主导感 |
| P2-E | 骑压 | 角色被按坐，指挥官跪于腿间仰头 | 髋压指挥官肩 | 压迫反转 |
| P2-F | 侧躺缠腿 | 指挥官侧贴，一腿插入其腿弯 | 膝勾住腰 | 缠绕 |
| P2-G | 细管预告 | 主管道外磨 + 手持细管在乳首画圈 | 胸颤+腿夹 | 预告 P4 |
| P2-H | 全身缠缚 | 指挥官四肢缠腰胯，像小型外骨骼 | 被钉在墙上感 | 无力挣脱 |
| P2-I | 耳语位 | 贴耳 + 管道抵腿根 | 侧颈红、耳抖 | 心理+生理 |
| P2-J | 反向榨取 | 角色主动用胸夹管道快速蹭 | 指挥官仰头漏油 | **角色反杀一寸** |

### 5.2 循环节拍建议

1. 0–1.5s：贴紧 / 摩擦启动  
2. 1.5–3s：一方漏油第一滴（高光）  
3. 3–4s：另一方腿软 / 腰弹  
4. 4–5s：略分离再贴回（loop）
