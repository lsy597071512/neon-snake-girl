## 三、通用检查

- [ ] 倒下：僚机整机隐藏 / 队长压暗 + "XX倒下"；按钮虚线灰；回血复活还原
- [ ] 状态环：定身金 / 冰冻蓝 / 灼烧橙 = 环 3.9 米 + 5.5 米柱 + 呼吸；死亡摘环
- [ ] 后仰：风刃命中整只后栽（3D）/ 挤压（贴图）；0.55 秒回正；Boss 只晃一下
- [ ] Raid Boss 关：CD 正常转、多段/炮弹/爱心照常结算、灼烧跳、按钮不灰死
- [ ] 性能：千元机技能齐放不掉帧（池 40 格 + 预留 12 格）；白块/糊屏立即报
- [ ] 横幅人话：无"弹伤"黑话；SR 按钮显示正确技能名（非乱码）
