# 本地生活档案（0 Token）

## 原则

**生活全量存本地，进模型只带薄 digest。**  
IndexedDB / localStorage 不计 API token；只有 Prompt 里那几行摘要才花钱。

## 写入时机

| 时机 | 内容 | 是否调 LLM |
|------|------|------------|
| 心跳巡检 | 全员位置/行为变化（有变才写） | 否 |
| 离线归来 | 快照 + 可选离线摘要文 | 摘要可选 |
| 营地氛围日志 | 短句事件 | 否 |
| NPC 对谈成功 | 事件摘要 | 是（已有） |
| 对话 | 另见 dialogueArchive | 是 |

## 压缩

条数 > 2500 时：旧明细按「游戏日」滚成 `day_digest`，保留近 800 条原文。  
文本量远低于 10GB；真到内存紧张会继续砍旧日明细。

## Prompt

对话时附加最多 4 条【你近日在营地的生活痕迹】——本地生成，0 API。
