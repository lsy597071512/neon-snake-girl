# 绯月级文案尺度规范（市场版）

> **对标物**：《绯月絮语》——国新出审〔2025〕1488号，深圳华文国际传媒发行，广州畅悦运营，B站官号 105 万粉丝、商店 189 万下载量。
> **核心口径**：**文案尺度 ≫ 画面尺度。线画在画面（露点 / 性部位特写 / 性行为描绘），不在文案。**
> 本项目市场版文案按「绯月级」执行。

## 一、为什么以绯月为标尺（实测依据）

抓取该游戏 B站官号 36 条投稿的完整标题与简介，实测其**官方宣发文案**直接使用以下词，且用于礼包码/标题这类最正式位置：

| 实际用词 | 出处示例 |
|---|---|
| 调教 | 「白龙的**调教**」礼包码 |
| 触手 | 「**触手**的黏腻邀请」「听说，**触手**可以让骑士大人更兴奋？」 |
| 敏感带 | 「**逆鳞是敏感带**」「**敏感**逆鳞」 |
| 舔 | 「就让我**舔**一口」「猫**舌**可是很灵活的」 |
| 惩罚 | 「请再打几下**惩罚**我」「你也不想偷偷**惩罚**我的事被人知道吧？」 |
| 服侍 / 摆弄 | 「跪下来**服侍**我吧」「可以随意**摆弄的玩具**」 |
| 私密 | Slogan：「指尖轻触，解锁她的**私密**絮语」 |
| 隐晦性行为 | 「**双宿双飞**」「明天就要有你的**宝宝**了」 |
| 撕开封印 | 「挥动女神之鞭、**撕开黄色封印**」 |

**结论**：在正规持版号渠道，官方文案可以大胆到「调教/触手/敏感带/惩罚/私密形态」这个程度而稳过审。

## 二、三层词表分级（`scripts/check-cloud-sensitive.mjs` 已实现）

| 层 | 词表 | 规则 |
|---|---|---|
| **T1 硬红线** | 乳头/乳晕/阴道/阴茎/肉棒/小穴/淫/勃起/发情/潮吹/射精/精液/口交/性交/做爱/自慰/会阴/肛交/裸体/全裸/露点/无罩/硬了 | **全库必须为 0**，越线即违规。校验器 `T1-HARD-REDLINE` 强制。 |
| **T2 文案可用·禁入 Prompt** | 调教/触手/拘束/敏感点/开腿/呻吟/娇喘/快感 | 可用于**人工固定文案**；**不得**作为 LLM 实时输出目标（模型自我审查/降智风险）。`src/ai` 下出现会告警。 |
| **T3 文案+Prompt 双安全** | 调情/撩拨/暧昧/私密/服侍/挑逗/情趣/撩人/勾人/风情/展示身材/惩罚/诱惑/独占/若即若离/玩心 | 文案层与 Prompt 层均可安全使用。 |

> 校验器采用**逐行扫描**，带 `t1-check-exempt` 标记的行跳过（仅用于云端正则的中和替换，如 `llmClient` 里的 `.replace(/全裸/g, '未裹巾')`）。

### 运行
```bash
node scripts/check-cloud-sensitive.mjs
# 期望输出：cloud-check: T1 clean (no hard-redline wording)
```

## 三、市场版文案尺度落地清单

### Prompt 层（LLM 输入，喂给 `qwen_plus_character`）—— 已到绯月级
- **暧昧语汇行**：调情、撩人、勾人、诱惑、贴身、私下、独占、宠你、玩心、若即若离、耳语、心跳、发烫、脸红、危险、只给你看。
- **爽点清单**：凑近、贴耳低语、挑下巴/按肩、拽衣袖、依赖式倚靠、半真半假吃醋、被看穿脸红、说完就撤的逗、危险浅笑、把「在意」包进玩笑。
- **好感分级**：低好感克制试探 → 高好感主动依偎/耳语/直球情话/独占意味（阈值 75，分档 85/95）。
- **inner_thought 作为「最能擦边的通道」**：口白矜持、心里主动。
- **14 条角色声线**各带 1 句样本台词（如「跟上我。看清楚——我可不常让人走这么近。」）。

### 固定文案层（人工写死）—— 已到绯月级
- **特殊服装 pifu05**：触发词含「主动调情 / 撩拨 / 诱惑 / 展示身材 / 贴身玩心 / 半真半假的独占」。
- **浴室互动**：帮洗氛围（指尖滑过肩背、水声与呼吸、湿发、发烫耳根）、共浴解巾玩法全保留。
- **皮肤动作 / 换装协议**同步 T3 语汇。

### 画面层（红线，不可越）—— 与文案无关
- **市场版上限 = 绯月 PV / 宣传图级**：全身、仰视、乳沟、短裙、水下、湿身打光；**零露点**。
- **硬禁**：露点、性部位（会阴/肛区）特写、臀部微距特写、湿身透点、开腿入裆、乳头/乳晕可见。

## 四、与「本地成人版」的隔离

- **本地版**（`_adult-local/`）：成人露点色情版，原始素材不打码，不送审、不进渠道。
- **市场版**（`src/`）：本规范约束的绯月级擦边版，是唯一送审打包源。
- **`asset-ship-filter.mjs`** 硬拦截 `tiaojiao/`、`luoti`、`moan`、`tiaojiaoqidong` 等成人资产，确保本地版素材绝不进 `dist`。
