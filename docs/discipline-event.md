## 1. 设计意图（Player Promise）

### 1.0 一句话重心（v0.5.1）

**小黑屋的主功能 = 指挥官对「不听话 / 多次冷落玩家」的惩罚与威慑工具。**  
角色在绝大多数调教会话里处于 **被动**；主动求进小黑屋是 **低概率支线**，不是主叙事。

### 1.1 两种完全不同的欲望方向

| | **pifu05（特殊服装01）** | **小黑屋调教事件（`tiaojiao` / 建议 `pifu06`）** |
|--|--|--|
| 欲望方向 | AI 想 **调情指挥官**（角色主动撩） | AI 被指挥官 **调教 / 惩罚**（角色多半被动；偶发主动求虐） |
| 谁发起 | 角色侧情趣意图为主 | **玩家惩罚/威慑为主**；角色主动求进为辅（低概率） |
| 结果本质 | 日常调情、展示、暧昧升温 | 约束、服从拉扯、惩罚余波、复杂被动情绪 |
| 结论 | **两套完全不同的结果，禁止混用关键词与皮肤** | 同上 |

### 1.2 小黑屋在玩法闭环里的位置

游戏中 AI 有自主行动，可能：
- 拒绝指令、冷处理、不回消息、多次「不搭理」玩家；  
- 或口头顶撞、拖延、敷衍。

此时指挥官可用小黑屋：

1. **威慑（未进入）**：对话中威胁「再不听话 / 再不跟我聊，就把你拖进小黑屋」。  
   - AI 必须 **读懂威胁**，结合性格·好感·社交·此刻想法，决定 **顺从求饶 / 嘴硬试探 / 继续顶撞** 等。  
   - 顺从 ≠ 系统写死服从度；只是本轮对白与后续短时态度可能软化。  
2. **执行（进入）**：玩家点「小黑屋」或兑现威胁 → 黑屏拖入负一楼调教室 → 强制调教皮 → 被动调教会话。  
3. **事后**：结算好感/疲劳 + 记忆钩子；是否「学乖」仍由 AI 人格决定，系统不写死听话。

**角色主动求进**：仅当强受虐/缺爱欲望触发时，**低概率**提出；不得与「想穿 pifu05 调情」混为一谈。

**目的（系统侧）**  
- **不保证**角色永久变听话；只写入状态、记忆、好感/疲劳  
- 威慑阶段与执行阶段都要给 AI 足够上下文，使其能「怕惩罚」或「嘴硬」  
- 效果影响 **会话中对白** 与 **之后** 行为，不当场永久改人设

## 2. 核心规则（可实现）

### 2.1 触发（主从分明）

| 入口 | 权重 | 条件 | 表现 |
|------|------|------|------|
| **A. 玩家「小黑屋」按钮（主）** | **主路径** | 开关默认开；对话页目标角色；常因不听话/冷落而点 | §12 进入流程（惩罚执行） |
| **B. 对话威慑（主·未进房）** | **主路径** | 玩家口头威胁拖进小黑屋 | **不换房**；只注入威慑上下文，AI 当轮判断是否顺从 |
| **C. 角色主动求进（辅）** | **低概率** | 强缺爱/受虐欲望等（§12.8）；远低于 A/B | 玩家确认后才进入；拒则写记忆 |

进入房间后统一：黑屏 → 拖入负一楼 → 强制调教皮 → `disciplineActive=true` → **角色以被动约束态为主**。

### 2.2 开关

| 项 | 规则 |
|----|------|
| 全局 / 角色级开关 | 关闭后：UI 不显示「小黑屋」；威胁文案可不注入专属块；角色不得主动求进；已在调教中可强制结束并结算 |
| **默认** | **开启** |

### 2.3 疲劳

- 每次进入调教并完成（或中途强制结束）→ 给该角色增加 **`fatigue`（疲劳）** 状态（复用现有 `characterStatus` / `livingState` 标签体系）。  
- 多次调教可叠加疲劳强度 / 持续时间（具体数值表 → Phase-2+ 系统，本文先定「会加疲劳」）。

### 2.4 听话与否（关键边界）

- **禁止**：调教后强制写死「服从度 = 100」或强制同意所有指令。  
- **允许**：写入状态标签（如 `bound_calibrated` / `post_discipline`）、短期记忆钩子、情绪偏移提示。  
- **由 AI 决定**：后续对话、是否愿意教练 / 互动 / 服从，仍走角色人格 + dayMode + traits + 记忆；调教只是强刺激输入。

### 2.5 影响范围

| 影响 | 说明 |
|------|------|
| ✅ | 后续行为权重、情绪、疲劳、房间偏好、对话语气、对指挥官态度 |
| ❌ | 不直接改写战斗数值（除非另开系统案） |
| ❌ | 不在调教演出中「当场永久改人设」 |

### 2.6 内容与安全边界（美术 / 演出）

- **擦边允许**：束缚、敏感、喘息、腿根 / 腰臀压迫、布料绷紧、无法挣脱的张力。  
- **禁止**：露点、露阴、明确性行为完成态、儿童化描写。  
- 服装：**本期不定稿**，由服装设计方另出；动作表只锁 **身体姿态 + 机械臂缠绕点 + 表情**。

## 12. 小黑屋会话版（v0.5.1 · 对话页玩法）

> 本节是 **聊天界面内调教事件** 的实现规格。Phase-1 美术表（§5–§8）仍有效；会话态皮肤优先用已入库的 `tex/juese/pifu/tiaojiao/{Stem}_tiaojiao.webm` + `_N`。

### 12.1 场景定位与美术

| 项 | 规格 |
|----|------|
| UI 文案 | 按钮文案：**小黑屋**（= 机器人调教室） |
| 世界坐标 | **负一楼**（B1）；与现有 1F/2F 营地楼层并列，需新增 `room_b1_discipline`（或等价 id） |
| 背景图 | `tex/Indoor/shinei01_tiaojiaoshi.png`（昏暗；触手工具 / 调教设备） |

### 12.1.1 双态（v0.6 · 强制）

| 态 | `poseIndex` | 立绘 | 含义 | UI |
|----|-------------|------|------|-----|
| **未调教 / idle** | `null` | `{Stem}_tiaojiao.webm` 循环 | 已进小黑屋、穿约束皮，**尚未**进入触手加压姿势 | 按钮 **「默认」**（高亮） |
| **触手调教** | `1..N` | `{Stem}_tiaojiao_N.webm` **循环粘住** | 正在进行对应触手姿势 | 按钮 **「姿势N」**（高亮）；数量 = `secondaryCount` / 磁盘 `_N` 数 |

进房必须落在 idle。切姿势后立绘不得播完回 idle。点「默认」才回 idle，并通知 AI「已解除触手加压姿势，回到未调教待机」。

### 12.2 对话页 UI 状态机

| 状态 | 「小黑屋」按钮 | 📦 送礼/递物 | 姿势切换 | 背景 / 立绘 |
|------|----------------|--------------|----------|-------------|
| 日常对话 | 显示「小黑屋」 | 可用 | 隐藏 | 当前营地场景 + 当前营地皮 |
| 进入过渡中 | 禁用 | 禁用 | 隐藏 | 黑屏淡入淡出（约 1.5–3s，可配） |
| 调教中 | 文案变为 **「离开」** | **禁用** | **默认** + 姿势1..N | 调教室 BG + idle 或当前粘住姿势 |
| 离开过渡中 | 禁用 | 禁用 | 禁用 | 黑屏淡入淡出 → 恢复进入前场景/皮肤 |

### 12.3 进入流程（玩家点「小黑屋」/威胁兑现，或确认角色邀请）

1. 记录会话快照：`prevRoomId`、`prevCampSkinId`、`prevSkinClip`、`characterId`、`startedAt`。  
2. 黑屏 **淡入 → 短停（留给换皮/换景）→ 淡出**。  
3. 强制：`roomId = room_b1_discipline`；`campWornSkin = pifu06/tiaojiao`；`skinClip = null`（播 idle）。  
4. 置位：`disciplineActive=true`；锁定该角色 `characterAgenda`；清掉未完成的 `pendingItemOffer`（退回仓库）。  
5. 向对话日志注入 **系统可见文案**（玩家气泡或系统行，二选一，建议系统行 + AI 上下文块）：  
   - 例：`【系统】指挥官将{名}拖入负一楼小黑屋（机器人调教室）。`  
6. 向本轮及后续 Prompt 注入 **§13.1 沉浸块**（场景 + 状态 + 当前 idle/姿势文字解读）。  
7. 角色进入调教态后，首轮可主动短反应（可选 `want_continue`），必须表现出「发现自己在哪、穿什么、被约束」。

### 12.4 姿势切换（对标送礼递物）

逻辑对齐「仓库递物」：玩家操作 → **变成一条玩家侧文本发给角色** → 等角色回应；UI 需冷却。

| 项 | 规则 |
|----|------|
| UI | **「默认」**（idle）+ 「姿势1..N」（有几个 `_N` 显示几个；按钮数必须与 `portraitLiveSecondaries.length` / `secondaryCount` 同步） |
| 点姿势N | ① 立绘切到 `_N` **并循环粘住**；② 发送玩家文本 `（你将拘束姿态切换为姿势{N}：{短描述}）`；③ Prompt 当前画面=姿势N |
| 点默认 | ① 立绘回 idle 循环；② `poseIndex=null`；③ 发送 `（你解除触手加压姿势，让她回到未调教待机：{idle短描述}）`；④ Prompt 当前画面=idle |
| 冷却 | **二者取严**：角色尚未完成本轮回应 **或** 距上次切换 &lt; **20s** → 按钮禁用（含默认↔姿势） |
| 禁止 | 冷却期内连点；跨皮肤播别的皮的 `_N`；调教中用 `skin_change` 逃出调教皮；姿势播完自动回 idle |

### 12.4.1 姿势文案锁资产（v0.6）

- 每次新增/删减/替换 `{Stem}_tiaojiao_N.webm`：**先看帧写姿势短描述**，再写入 `disciplinePoseNotes.ts`，保证文字与画面一致。  
- 编号压紧后必须同步 `secondaryCount` 与文案表 key（1..N 连续）。  
- AI 只读运行时 `getDisciplinePoseNote`；禁止在 Prompt 里手写与资产不符的姿势。

### 12.5 调教中对话

- 可正常打字/语音聊天。  
- 每轮 Prompt 必须带：场景（负一楼小黑屋）、`disciplineActive`、当前皮 idle/姿势文字、设备与触手约束事实。  
- 情绪空间（须结合 **性格 · 好感 · 社交 · 当前想法** 综合判断，禁止全员同一句）：  
  气愤、讨厌、兴奋、渴望、喜欢、溺爱、敏感、尴尬、窘迫、激动、害怕、伤心、疲惫、厌恶、情趣、激昂、混乱、淫乱、话语擦边、羞愧、害羞、紧张、亢奋…  
- 输出建议增加结构化字段（见 §13.2）：`discipline_mood`、`discipline_valence`（tragic|mixed|joyful）。

### 12.6 结束条件（任一即结束）

1. 玩家点击 **「离开」**（原小黑屋按钮）。  
2. 玩家 **关闭聊天页、切换到另一段对话或离开该页面**。  
3. **网络断开、页面卸载、应用退到后台、进程卡死、退出/重启游戏、读档覆盖会话** 等异常中断。  

所有终止路径必须在检测到中断时**立即**走同一个幂等结算出口：解除束缚、还原位置和事件皮、解锁日程、写记忆与疲劳，并持久化存档。仅玩家点击「离开」且窗口仍在时可以额外等待静默 `discipline_settle` 裁决；关闭、断线、退出与重启绝不能等待网络，直接使用已记录的 `valenceHints` 回落结算。  

结束流程：

1. 黑屏淡入淡出。  
2. 恢复 `prevRoomId` + `prevCampSkinId`（若无则默认装甲/原皮）。  
3. `disciplineActive=false`；解锁日程。  
4. **结算**（§12.7）。  
5. 写一条记忆钩子（短）：场景、主要情绪走向、结局类型。  
6. 注入一轮可选「离开后余韵」对白（不强制）。

### 12.7 结局结算（悲情 / 欢乐）

| 结局 | 判定来源（建议） | 好感 | 疲劳 |
|------|------------------|------|------|
| **欢乐** `joyful` | 会话中 `discipline_valence` 以正/沉溺/情趣共鸣为主；或结束时 AI 显式 `joyful` | **+好感**（按人设钳制） | **+一定疲劳** |
| **悲情** `tragic` | 以厌恶/害怕/伤心/明确拒绝为主；或 AI 显式 `tragic` | **-好感** | **+疲劳**（可略高于欢乐） |
| **混合** `mixed`（可选） | 矛盾拉扯 | 好感微变或 0 | +疲劳 |

**判定落地（须实现时二选一并写死）**：  
- **推荐 A**：结束时多要一轮静默 `discipline_settle` JSON（仅 `valence` + `one_line_memory`），不刷玩家可见对白。  
- **备选 B**：对会话中各轮 `discipline_valence` 加权投票；无字段则回落启发式（关键词/emotion）。  

禁止：用单一固定数值无视人设；禁止悲情仍强制「更听话」。

### 12.8 对话威慑（主 · 未进房）与角色主动求进（辅 · 低概率）

#### 12.8.1 威慑（重点 · 必须同步 AI）

玩家在**日常对话**中威胁把角色拖进小黑屋（例：「你再不跟我说话 / 再不听话，就把你关进小黑屋」）。

| 项 | 规则 |
|----|------|
| 检测 | 关键词/意图：小黑屋、调教室、拖进去、惩罚、再不…就… 等 |
| Prompt | 当轮注入 **§13.0 威慑块**（未进房、未换皮） |
| AI 义务 | 必须读懂「惩罚威胁」；结合性格·好感·社交·是否刚冷落过玩家，决定：求饶顺从 / 讨价还价 / 嘴硬试探 / 继续冷落顶撞 |
| 系统 | **不**因此自动进房；**不**改服从度数值；仅影响本轮对白与可选短时软化标记 |
| 兑现 | 玩家随后点「小黑屋」= 执行惩罚；`entrySource='threat_fulfilled'` |

#### 12.8.2 角色主动求进（辅 · 低概率）

- **默认权重低**：多数会话不应出现；与「想穿 pifu05 调情指挥官」完全无关。  
- 仅当人设允许且欲望极强（强受虐 / 极端缺爱且明确求惩罚）才可提出。  
- 流程：角色提出 → 玩家确认 → §12.3；拒绝 → 记忆「指挥官拒绝了进小黑屋」。  
- 实现：日冷却 + 概率门（基础概率宜低，再乘人设系数），避免刷屏。

## 13. AI 同步规格（必做）

### 13.0 威慑块（未进房 · 日常对话当轮注入）

当检测到玩家威胁小黑屋，且当前未在调教中、开关开启时注入：

```text
【世界同步·小黑屋威慑·本轮】
- 指挥官正在用「拖进负一楼小黑屋（机器人调教室）惩罚你」作为威胁；你此刻仍在原场景，尚未被拖入。
- 小黑屋 = 你不听话 / 冷落玩家时的惩罚工具，不是情趣调情，也不是换 pifu05。
- 你必须结合性格、好感、社交、是否刚怠慢过指挥官，自行选择：害怕求饶并答应聊天或听话、讨价还价、嘴硬挑衅、或继续冷淡——禁止无视威胁装没听见。
- 顺从只是你的对白态度，系统不会改写服从度数值；若指挥官真的按下「小黑屋」，你会被强制拖入调教室并切换调教约束皮。
```

### 13.1 运行时沉浸块（每轮注入）

进入调教后，Assembler 必须注入类似：

```text
【世界同步·小黑屋调教中·最高优先】
- 地点：负一楼机器人调教室（小黑屋）。昏暗；可见拘束设备与指挥官侧机械触手工具。背景即玩家所见。
- 状态：disciplineActive=true。你**已被拖入小黑屋并锁在调教室**，穿着约束皮；**无法自行离开、无法逃走、无法用 end_conversation 关窗逃掉**。触手是否缠身必须以「当前画面」为准（idle=尚未缠身；姿势N=触手加压中）。
- 因果：常见是指挥官认为你不听话、冷落或不愿搭理；少数才是你主动求进（低概率）。与「你想调情指挥官（pifu05）」完全不同。
- 穿着：调教专用皮（白皮衣/约束态动态），不是日常装甲，也不是 pifu05 情趣装。
- 当前画面：{idle未调教 | 姿势N触手调教} — {面向玩家的一句动作/束缚文字解读；必须与当前 webm 一致}
- 双态：idle = 已进房但尚未触手加压姿势（禁止写触手缠身/挣脱束缚）；姿势N = 正在进行触手调教。切换时玩家消息会写明姿势，必须先用身体/喘息回应。
- 规则：谈及衣装/地点/是否被触手缠住必须与上一致；禁止假装还在大厅/浴室；禁止 skin_change / move_to 逃出本场景；**end_conversation 必须 false**。
- 情绪：结合你的声线、好感、社交、此刻想法，表现气愤、害怕、屈辱、羞愧、紧张、疲惫等，并允许有限的矛盾；禁止全员同一句拒绝模板。
- 兴奋情绪不是禁用项：根据角色综合状态（情绪连续体、好感、今日模式、traits、入口原因和当前姿势）按概率选择是否呈现「兴奋、渴望、溺爱、淫乱、亢奋」等成人向兴奋表现。低唤醒/低好感/高警戒时以反抗、害怕或紧绷为主；高唤醒且关系温度较高时，这些兴奋词可以成为主导或与抗拒、羞耻、紧张并存。不得把全员固定为反抗，也不得把兴奋写成每轮必然发生。
- 概率是表现倾向，不是强制结果：没有抽中时仍可保留少量身体敏感、矛盾或好奇，但应服从角色当下状态；不得因为出现兴奋情绪而改变调教室地点、无法自行离开，或把 idle 误写成已触手缠身。
- 姿势切换：若本轮玩家消息含「切换拘束姿势」，先用身体/喘息/短句回应该姿势的触感，再继续对话。
```

**刚进房（`justEntered`）**：进房黑屏后立即触发一轮 proactive，动机为「发现自己已被拖入小黑屋（idle 未调教，尚未触手缠身）」；Prompt 追加硬锁定——禁止再说「我不进去/别提小黑屋」等尚未进房台词，也禁止 idle 轮描写触手已缠身。引擎侧强制 `end_conversation=false`，Overlay 忽略结束关窗。

**刚离房（`justLeft`）**：离开后写入对话短窗系统事实 + 立即触发 proactive「束缚已解除」反应轮（与进房对称）；注入 3 轮解除束缚块；中止在途对白；还原进房前事件临时皮；清孤儿议程/锚点；立绘刷新须重建皮肤层。读档若 `settling` 卡死须 `force` 结算，避免永久锁房。**在应用挂载前与从标题页重新进入游戏前，也必须同步执行同一恢复流程**，避免没有重新读取 localStorage 的进程内旧会话继续显示调教室或约束皮。

姿势切换时追加玩家可见文本 + Prompt 一行：`【指挥官将拘束姿态切换为姿势{N}】{短描述}`。

| `campOutfit` / 事件临时皮 | 进入写调教皮，离开还原；不碰看板娘 |
| 营地房间表 | 注册 B1 调教室 + 背景路径 |
| 记忆 / 疲劳 / 好感 | 结算钩子 |

### 13.4 姿势文字解读（程序生成模板）

对每个角色、每个 `poseIndex`：

- `0/idle`：锁 `{Stem}_tiaojiao.webm` 画面——通常为白皮衣/约束装待机，**尚未**被触手加压姿势缠满（进房默认）。文案须写「未调教待机」。  
- `N`：锁 `{Stem}_tiaojiao_N.webm` 画面写短描述（触手缠绕点、身体角度、表情）；无专表时用通用句 + N。

## 14. 分析：遗漏 · 风险 · 不足（评审结论）

### 14.1 方案优点（v0.5.1 重心）

- **惩罚/威慑主路径清晰**：不听话或冷落 → 玩家威胁 → AI 判断是否顺从 →（可选）拖入小黑屋。  
- 与 pifu05「角色想调情指挥官」欲望方向完全拆开。  
- 角色主动求进降为**低概率**辅路径，避免喧宾夺主。  
- 进房后角色以被动约束态为主；姿势切换 / 结束结算 / 悲喜好感仍保留。

### 14.2 必须补清的遗漏

| # | 遗漏 | 建议 |
|---|------|------|
| 1 | **悲/喜谁裁决**未算法化 | 采用 §12.7 推荐 A（结算静默 JSON） |
| 2 | **进入前皮肤恢复**未写死 | 快照 `prevCampSkinId`，离开必还原 |
| 3 | **B1 楼层**未进现有 `campFloor`（仅 1/2） | 新增房间 id + 地图/传送；对话可只换 BG 不先做地图 |
| 4 | 调教皮 **无顶层 PNG poster** | 用 webm 首帧或抽帧作 poster，防黑闪 |
| 5 | **威慑检测**与「冷落」量化不足 | 连续敷衍/拒聊计数 + 威胁关键词；主动求进另计且低权重，并加日冷却 |
| 6 | **同屏多人对话**是否允许调教 | 建议 Phase-1 **仅 1 对 1** |
| 7 | 调教中 AI 填 `skin_change`/`move_to` | 服务端忽略或钳制 |
| 8 | 关闭页 vs 点离开 **双重结算** | `ending` 幂等锁 |
| 9 | 「需求未满足」量化 | 先做简单计数（N 日无亲密互动）+ 记忆关键词，再迭代 |
| 10 | 姿势短描述表 | 无表时 AI 只能盲猜触感；至少通用模板 + 逐步补 §6 |

### 14.3 风险

| 风险 | 等级 | 缓解 |
|------|------|------|
| 强制拖入 vs 角色邀请的伦理观感 | 中 | 设置开关；邀请走确认；文档写明强制玩法边界 |
| 内容审核 / 商店上架 | 高 | 保持擦边规格；可关功能；无露点完成态 |
| LLM 无视场景仍说在大厅 | 高 | §13.1 最高优先 + 违规重抽/硬修正 |
| 20s 冷却与「等回应」死锁（AI 失败） | 中 | AI 失败/超时也解除 `awaitingPoseReply` |
| 断线读档卡在调教态 | 高 | §12.9 读档自动结算 |
| 好感暴涨暴跌 | 中 | 沿用角色 `affMin/affMax` 钳制 |
| 与浴室同意门混淆 | 中 | Prompt 明确：小黑屋≠浴室；不改 bath consent |
| 性能：黑屏+换 webm 卡顿 | 中 | 预加载调教 idle；过渡 2s 内完成 load |

### 14.4 实现优先级建议

1. **P0**：会话状态机 + 黑屏 + BG + 强制调教皮 + 离开结算 + Prompt 沉浸块 + 禁用送礼 + 拆 pifu05 关键词  
2. **P1**：姿势切换（文本+冷却+skin_clip）+ valence 结算  
3. **P2**：角色主动邀请 + B1 地图 + 分角色姿势文案表 + 静默 settle 轮
